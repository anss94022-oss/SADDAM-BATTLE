# SADDAM BATTLE — صدام بطل

لعبة أكشن عسكرية ثلاثية الأبعاد للأندرويد، تعمل دون إنترنت.
A 3D military action game for Android that runs fully offline.

Godot 4.3 · GDScript · Android ARM64 APK · GitHub Actions

---

## الحالة الحقيقية للمشروع (مُتحقَّق منها بالاختبارات)

هذا القسم يذكر ما يعمل فعلياً وما لم يُنفَّذ بعد. لا يُعتبر أي بند منجزاً
قبل أن ينجح اختباره في `tests/`.

يعمل ومُختبر آلياً:
- حملة من 12 مهمة بأنواع أهداف حقيقية: تصفية، صمود، إنقاذ رهائن،
  مرافقة قافلة، سيطرة على منطقة، تدمير مستودعات، تصفية قادة، الزعيم.
- لاعب بمنظور الشخص الثالث مع مجسّم جندي متحرك (مشي/جري/انحناء/تصويب/موت).
- 13 سلاحاً من ملف بيانات واحد (`data/weapons/weapons.json`) بمناظير 2x/4x/8x،
  قنابل يدوية، سكين، قاذف صواريخ، وعتاد علاج وذخيرة.
- أعداء بآلة حالات كاملة (دورية/شك/تحقيق/قتال/ساتر/التفاف/انسحاب/موت)،
  رؤية بمخروط، خط رؤية، سمع، تنسيق جماعي، تعزيزات، و7 أنواع أعداء.
- 6 خرائط مولّدة بخامات ونتوءات، إضاءة نهارية/غروب/ليلية وطقس غبار.
- 12 مركبة ودراجة ومروحية: ركوب/خروج، مقاعد، قيادة، ضرر وتدمير،
  طيران وطيران مروحي مع إقلاع وهبوط، وأصوات محركات ومراوح.
- واجهة عربية RTL وإنجليزية LTR قابلة للتبديل، مع خط Noto Sans Arabic.
- تحكم لمسي كامل وقابل للتخصيص (سحب الأزرار، حجم، مواضع محفوظة).
- حفظ محلي للخبرة والمستوى والعملات والأسلحة والإنجازات ونقاط الحفظ،
  مع نسخة احتياطية والتعامل مع ملف تالف.
- 31 مؤثراً صوتياً ومقطوعتي موسيقى مولّدة رقمياً (لا أصول مسروقة).
- ثلاثة مستويات رسومات (ULTRA/HIGH/PERFORMANCE) مع اقتراح تلقائي للجهاز.

لم يُنفَّذ بعد (لا تدّعِ خلاف ذلك):
- **اللعب الجماعي المحلي عبر Wi-Fi (2–5 لاعبين)** — لم يُكتب بعد.
  هذا هو البند الرئيسي المتبقي في المواصفات.
- اختبار على أجهزة أندرويد حقيقية (الاختبارات تعمل بلا شاشة فقط).


## الأصول الخارجية

- `assets/characters/soldier_vanguard.glb` — مجسم الجندي (Vanguard) من أمثلة three.js، وهو مبني على شخصية Mixamo. يُستخدم هنا كنموذج بطل/عدو مع تحريك Idle/Walk/Run. رخيصته الأصلية تسمح بالاستخدام في المشاريع؛ استبدله بمجسم مرخّص خاص بك قبل النشر التجاري إن أردت ضمانًا كاملًا.
- أصوات الموسيقى والمؤثرات مولّدة رقمياً داخل المشروع (`tools/gen_audio.py`).
- سيارات المشروع: نماذج GLB بأسلوب Kenney (CC0) مع مواد طلاء جديدة.

## البناء (APK)

البناء يتم في GitHub Actions عبر `.github/workflows/android-build.yml`:
Godot 4.3 + قوالب التصدير 4.3 + Java 17 + Android SDK 34، تصدير ARM64،
ثم التحقق من وجود الحزمة وحجمها ورفعها كـ Artifact.

التوقيع: لا تُخزَّن أي مفاتيح توقيع في المستودع. يُنشئ سير العمل مفتاحاً
وقت البناء من أسرار المستودع (إن وُجدت) أو مفتاحاً مؤقتاً للاختبار.

## التحكم

حاسب: WASD حركة، فأرة نظر/إطلاق، زر أيمن تصويب، R تلقيم، Q تبديل سلاح،
E تفاعل/ركوب، G قنبلة، H علاج، C كاميرا المركبة، V تقريب المنظار،
Shift ركض، Ctrl انحناء، مسافة قفز، Esc إيقاف.

لمس: عصا يسار، سحب يمين للنظر، أزرار إطلاق/تصويب/تلقيم/سلاح/قفز/انحناء/
قنبلة/علاج/تفاعل/ركض/منظار/كاميرا — كلها قابلة للسحب والتغيير من الإعدادات.

## هيكل المشروع

```
data/           أسلحة، مركبات، أعداء، مهام، ترجمات (JSON)
assets/         خامات وصوت وخطوط (كلها مولّدة أو مرخّصة)
scripts/        main, player, ai, missions, vehicles, world, ui, save,
                settings, audio, localization, core
tests/          project-check, gameplay
tools/          مولّدات الخامات والصوت
.github/        سير عمل التحقق والبناء
```
